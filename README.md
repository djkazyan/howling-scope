iPhoneのブラウザで https://djkazyan.github.io/howling-scope/ を開き「マイクを開始」でスタート
ピンクノイズ等の一定の音量の音を出し、Apple Watchの騒音計を見ながら Howling-scopeの音圧の構成に平均値を入れて基準にする 測定は「A」で行う

最終的に、現場はCかZ推奨
<種類	特徴	使い道>
Z	補正なし。全帯域をそのまま測る	実際のレベルを見たいとき
C	ほぼ補正なし。極端な低音と高音だけ少し削る	ライブ、PAの音量管理
A	低音を大きく削り、人の耳の感じ方に近づける	騒音規制、環境騒音の測定

ライブハウスで音量を見るなら、CかZが実態に近いです。Aは低音（キックやベース）をかなり小さく表示するため、体感より低い数字になります。会場の基準や規制がdB(A)で決まっているなら、それに合わせます。
A・C・Zはメーターの数字だけを変えます。ハウリングの検出、スペクトラム、リストには影響しません。
dbはあくまでも参考程度(iPhoneマイクの限界)
